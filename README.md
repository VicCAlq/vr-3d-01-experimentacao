O relatório que vocês devem escrever já vai conter os tópicos a serem explorados. Para ajudar a organizar, abaixo vocês verão como formatar o documento:

## Sintaxe de Markdown

Títulos são escritos com # na frente:
```Markdown
# Título grandão
## Título grandinho
### Título médio
#### Título pequeno
```

Listas numeradas são escritas assim:
```Markdown
1. Primeiro item
2. Segundo item
3. Terceiro item
```
E são exibidas assim:
1. Primeiro item
2. Segundo item
3. Terceiro item


Listas sem números são escritas assim:
```Markdown
- Primeiro item
- Segundo item
- Terceiro item
```
E são exibidas assim:
- Primeiro item
- Segundo item
- Terceiro item

Caixas de marcação (checkboxes) são feitas assim:
```Markdown
- [ ] Caixa de marcação desmarcada
- [x] Caixa de marcação marcada
```
E são exibidas assim:
- [ ] Caixa de marcação desmarcada
- [x] Caixa de marcação marcada
